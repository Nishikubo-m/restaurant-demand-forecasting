## ノートブックの再実行検証

全ノートブックをそれぞれ独立した Jupyter カーネルで先頭から実行する。元のノートブックや保存済み出力は変更しない。実行にはローカルのカーネル通信、全入力データ、ログ集計の時間とメモリが必要。

```bash
uv run python eda/verify_notebooks.py --report output/eda/notebook_verification.json
# 特定のノートブックだけを確認する場合
uv run python eda/verify_notebooks.py eda/20_cold_start.ipynb
```

コマンドを実行した Python 環境を使う一時カーネルを作成する。検証前後で `input/` 直下のファイルと ZIP（アーカイブファイル自体）、ノートブック、`pyproject.toml`、`uv.lock`、検証スクリプトのハッシュを照合する。`--report` は全対象が成功した場合のみ書き出し、これらのハッシュ、ファイルサイズ、使用パッケージのバージョンを記録する。入力内のサブディレクトリは対象外。失敗時に既存レポートは更新しないため、日時とハッシュを確認する。`output/` は Git 管理対象外。

## 主な発見

- 学習データは920,640行、予測枠は306,600行。予測枠の0は初期値であり、実績ではない。学習データの売上ゼロは約26.49%。
- カタログ販売期間外の228,640行はすべてゼロ。期間内のゼロ15,272行には、コラボ企画の非参加店舗2,808行と、販売可能な12,464行が含まれる。販売可能なゼロの原因は特定できない。
- 価格と席は対象期間の各キーで欠落・重複なし。複数キャンペーンが同日に同一店舗へ適用される場合があり、単純結合で行を増やさないよう注意する。
- 来店2,491,880行と注文明細8,417,590行を集計した。日×店舗×商品単位の注文明細売上と train、日×店舗単位の来店売上と注文明細売上の不一致はともに0件。
- 提出サンプルの352,118行は日次・月次の6層から構成され、日次層からの再集計と一致した。サンプルは予測例であり、正解データではない。
- 2025年の観測天候は欠損。予測時点は2024年末なので、2025年の天候実績や来店・注文実績を特徴量に使えない。過去の実績を使う特徴量も、検証の各時点で利用可能だった情報だけに制限する。

## 追加分析の発見と検証上の注意

- 販売期間とコラボ企画の参加店舗を両方考慮したところ、2022〜2024年に条件外で売上が正の行は0件だった。2025年にはカタログ期間内でも非参加のコラボ店舗に対応する432行がある。これは配布データでの確認結果であり、将来も必ず成立すると断定しない。
- 2025年の販売可能な予測枠230,028行のうち、過去に同じ店舗・商品・曜日で正の売上がない枠が324行あり、すべてコラボ商品だった。9つの店舗・商品の組み合わせに由来する。
- 2024年の1日あたり平均売上は、2023年と比べて店舗別に約−11%〜＋21%と変化が分かれた。全店一律の成長率では捉えにくい。
- 来店と注文の会計IDを全店舗で照合し、会計の片側のみ存在・金額・明細行数・グループIDの不一致はいずれも0件だった。
- 2024年の通年検証では、2022年の日平均で2023年を予測した誤差から6層の重みを再計算した。2022〜2023年の店舗・商品日平均、曜日別平均、販売条件を加味した曜日別平均の参考スコアはそれぞれ1.22467、1.19854、0.82814。2024年の1期間での診断値であり、公式の2025年スコアではない。
- 配布済み重みは2024年の実績を使って算出されている。2024年のモデル比較で使用すると検証年の正解が重みに入るため、提出ガイドの手順で検証年より前からスケールを作る。2024年は閏年であり、重みに用いる行数も2025年と異なる。
- 価格・施策・席レイアウトの前後比較は季節や他の変化が混在する観察結果。因果効果や価格弾力性と断定しない。
- 同じ店舗・年・月・曜日で比較できる層に限ると、雨日と晴日の売上差は立地ごとに異なる。祝日も、オフィス街と他の立地では異なる傾向が見られる。いずれも交絡が残る観察上の差であり、因果効果ではない。
- 2,337,482会計のバスケットを集計。販売期間やセットメニューが共起やliftに影響するため、同時購入だけで施策の効果を判断しない。
- 期間限定商品の組み合わせでは、一括集計した高いliftが店舗・年・月別に期待共起数を算出すると大きく下がる例があった。ただし曜日・客層・共通販売日などの影響は残る。
- 売上を「来店組数／日 × 着席率 × 着席組あたり売上」に分けると、店舗ごとに変化の方向が異なる。これは恒等式に基づく記述であり、施策の因果効果ではない。
- 2024年末時点で2025年を一括予測する場合、7日前の実績を参照できるのは最初の7日、364日前は364日。曜日の揃う371日前は全365日で基準日以前となる。2024年の通年検証は閏年である点も注意する。
- 注文明細8,417,590行の数量×定価・値引き後金額を価格履歴と照合した結果、不一致は0件。クーポン適用186,619行の日付・店舗・対象カテゴリにも不一致はなかった。
- 来店2,491,880組の記録では、検査した状態・時刻・待ち時間・卓定員に不一致は0件。同日・同一卓に限る着席時間の重なりも0件だった。日をまたぐ卓利用は対象外。
- 着席・退店から分単位で復元した卓定員の利用状況では、営業時間中に当日の総席数を超える分は0件。90%以上の割合は探索用の閾値であり、満席や入店不能を直接意味しない。
- 全注文を来店と照合したところ、ランチ商品764,989明細に11:00前・14:30以後の記録はなかった。最初の注文より後の時刻に明細がある会計は540,946件（約23.14%）。同じ分の追加注文は区別できない。
- 販売可能な689,192行のうち12,464行（約1.81%）はゼロ。過去の構成では店舗・カテゴリ・曜日によって割合が異なるが、欠品などの原因は記録から確定できない。
- 2025年の未観測コラボ9店舗・商品ペアすべてに、他店舗で同一商品が販売可能だった過去履歴があった。単純な他店舗平均は企画・価格・客層等の差を調整しないため、2024年の小規模な参考比較だけで有効性を確定しない。
- 施策が同日・店舗・カテゴリで複数予定された過去の注文明細は8,871行。クーポン付与は予定と異なり、粗い条件一致の全明細を分母にした割合は、顧客の実際の利用資格を考慮した利用率や因果効果ではない。

## 入力ミスの候補を探す追加点検

`uv run python -m eda.22_data_quality` は売上キーの欠損・重複、負値・欠損、および年×店舗×商品×曜日の売上中央値に対する極端値を表示する。全期間を対象とする診断であり、2024年検証にそのまま学習特徴量や削除規則として使わない。

- 売上キーの欠損・重複、売上の負値・欠損は各0行。
- 中央値が正の645,804行のうち、中央値の10倍超は5行。すべてキッズ商品で、4行は祝日、残る1行は12月25日だった。需要変化や小さな中央値による可能性があり、入力ミスと確定していない。
- この比較は各年内の同じ店舗・商品・曜日を基準とする粗い探索で、販売期間やキャンペーンを調整していない。真値の外部照合や同じ誤りが複数ファイルに入った場合は検出できない。
