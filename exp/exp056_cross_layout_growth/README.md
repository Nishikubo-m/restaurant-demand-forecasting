# exp056: レイアウト水準を調整した前年ペア

- 仮説: EDA 08・13で席構成の変更と店舗水準の変化が観察された。exp054で同一レイアウトの前年比が不足する店舗は、レイアウト別水準を除けば変更前後の履歴も参考にできる可能性がある。
- 変更: exp054の直近3か月の前年同曜日ペアが14組未満の店舗では、過去の店舗・レイアウト・曜日別平均で数量相当売上を割った値を用い、レイアウトをまたぐ前年ペアの前年比を算出する。こちらも14ペア以上が必要で、足りない場合は元の平均倍率に戻す。それ以外の予測は変えない。
- レイアウト別水準には年次変化や季節の差も含まれ、因果効果ではない。検証は2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp056_cross_layout_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.382160**（exp054: 0.374623）。日次行 RMSE: **2,787.302円**。
- レイアウトをまたぐ前年ペアで補完した店舗は 6店舗。
- 保存先: `output/runs/20261117_022343_193794_exp056_cross_layout_growth/`。悪化したため採用しない。レイアウト平均に年次変化が混入した可能性がある。
