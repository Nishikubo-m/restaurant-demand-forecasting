# exp008: 店舗別の年次変化

- 仮説: EDAで店舗ごとに売上の年次変化が大きく異なり、exp006でも月×店舗の誤差が比較的大きい。
- 変更: exp006の平均予測に、店舗ごとの「直近年 / その前年」の日平均数量相当値の比率を掛ける。年次比較は通年販売のcore商品に限り、数量相当値は売上÷割引前価格。推定には予測基準日より前の履歴のみを使う。
- 検証: 2022〜2023年から2024年を一括予測。2024年の価格・販売・企画予定が2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp008_store_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.593427**（exp006: 0.626834）。日次行RMSE: **3,060.508円**。
- 保存先: `output/runs/20261117_010743_734847_exp008_store_growth/`。
- 店舗別の過去の年次比率を反映して改善したが、2024年1年のみの結果であり、比率が翌年も継続する保証はない。
