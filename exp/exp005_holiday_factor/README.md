# exp005: 店舗・曜日別の祝日倍率

- 仮説: EDAで祝日と同じ曜日の非祝日には立地・店舗による売上差が見られた。
- 変更: exp004の予測に、過去の店舗×曜日別の「祝日の平均店舗売上 / 全日の平均店舗売上」を祝日のみ乗算する。基準日以前の日次売上だけから計算し、過去の祝日サンプルがない場合は倍率1とする。予測モデルと直近年の重みは維持する。
- 検証: 2022〜2023年の情報で2024年を一括予測。2024年の販売・企画予定が2023年末に既知と仮定。6層尺度は2022年平均→2023年の誤差を使用。
- 実行: `uv run python -m exp.exp005_holiday_factor.run`

## 結果

- 2024年の6層正規化 RMSE: **0.741816**（exp004: 0.757162）。日次行RMSE: **3,310.482円**。
- 層別正規化RMSE: 日×店舗×商品 0.563669、日×店舗 1.009715、日×商品 0.297189、月×店舗×商品 0.398784、月×店舗 1.290835、月×商品 0.225592。
- 検証の祝日17,640行すべてに過去の倍率を利用できた。
- 保存先: `output/runs/20261117_010525_501420_exp005_holiday_factor/`。
- 2024年だけのローカル検証であり、他年の安定性や予定の事前利用可能性は未確認。
