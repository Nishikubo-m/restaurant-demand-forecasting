# exp011: 同一レイアウトの過去平均

- 仮説: EDAで席レイアウト変更の前後に来店・離脱の変化が見られた。店舗の過去平均を同じレイアウトの期間に絞ると、水準の変化を捉えられる可能性がある。
- 変更: exp009の平均にレイアウト版を追加し、「店舗×商品×レイアウト×曜日」の販売可能日平均を優先する。該当履歴がなければ元の平均に戻す。レイアウトの適用期間は配布の予定を使用し、その他の補正と平均モデルは維持する。
- 検証: 2022〜2023年から2024年を一括予測。2024年の価格・販売・企画・席の予定が2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp011_layout_means.run`

## 結果

- 2024年の6層正規化 RMSE: **0.763858**（exp009: 0.593219）。日次行RMSE: **3,393.469円**。
- 保存先: `output/runs/20261117_011013_260472_exp011_layout_means/`。
- 悪化したため採用しない。レイアウト別の履歴が短くなり、平均が不安定になる可能性がある。
