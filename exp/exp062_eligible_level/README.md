# exp062: 商品の販売可能日数に応じた直近水準補正

- 仮説: EDA 19・20では商品ごとに販売期間・コラボ参加店舗が異なる。exp060の直近水準補正は全商品について過去年数を同じ重みと近似しており、実際の販売可能日数とずれる可能性がある。
- 変更: exp060の水準補正における直近年・それ以前の比重を、店舗・商品・曜日別の販売可能な履歴日数から求める。直近年3倍・過去年1倍は維持し、該当する直近履歴がない場合はexp060の補正に戻す。店舗ごとの前年比が各商品に共通するという近似は維持する。
- 検証: 2022〜2023年を履歴、2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。限定商品での日数不足に注意する。
- 実行: `uv run python -m exp.exp062_eligible_level.run`
