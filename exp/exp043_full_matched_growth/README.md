# exp043: 同一レイアウトの年次変化が全量続く仮定

- 仮説: EDA 13の店舗ごとの年次変化が、予測年にも同程度続く可能性がある。
- 変更: exp042の同一店舗・レイアウト・月・曜日の年次変化について、半分ではなく全量が続く固定の仮定に変更する。履歴の条件や欠損時の補完は同じ。年次変化の外挿が続く保証はない。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp043_full_matched_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.388937**（exp042: 0.384175）。日次行 RMSE: **2,793.108円**。
- 保存先: `output/runs/20261117_020628_414187_exp043_full_matched_growth/`。
- 半分を反映する方法より悪化したため採用しない。
