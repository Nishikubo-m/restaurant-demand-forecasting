# exp057: 定価変更後の数量一定という仮定

- 仮説: EDA 08の価格改定前後の変化は季節や施策が混在する。数量反応が小さい場合、exp054の一律の価格反応が過大な可能性がある。
- 変更: exp054の予測から「価格の変化率の半分だけ数量が逆方向に変わる」という倍率を取り消し、定価変更によって数量は変わらないという固定仮定にする。その他の処理は変えない。
- 検証: 2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。この期間の履歴には定価変更がなく、価格の因果効果や弾力性を推定したものではない。
- 実行: `uv run python -m exp.exp057_constant_quantity.run`

## 結果

- 2024年の6層正規化 RMSE: **0.404467**（exp054: 0.374623）。日次行 RMSE: **2,791.517円**。
- 保存先: `output/runs/20261117_022506_976367_exp057_constant_quantity/`。
- 悪化したため採用しない。2024年単独では数量反応の実値を断定できない。
