# exp042: 同一レイアウトで比較した年次変化

- 仮説: EDA 13では店舗別に来店・着席率が変化した。exp022の年間前年比にはレイアウト変更が混在していたため、同じレイアウトと月・曜日に限定すれば、構成変更と年次傾向を分けて比較できる可能性がある。
- 変更: exp040に、定番商品の数量相当値から店舗・レイアウト・月・曜日別の前年同条件比を算出し、店舗ごとに幾何平均した倍率の平方根を掛ける。各年2日未満・非正値などは除外、店舗に比較可能な履歴がなければ倍率1。変化の半分が続く仮定は事前に置いたものであり、因果効果ではない。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp042_matched_layout_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.384175**（exp040: 0.390239）。日次行 RMSE: **2,789.113円**。
- 比較可能な条件は 630 組、補正不能は 0 行。
