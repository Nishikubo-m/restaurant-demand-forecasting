# exp026: カテゴリ別の月次倍率

- 仮説: EDAで商品カテゴリの季節性や客層・時間帯別の構成が異なっていた。店舗別の月次変動はカテゴリによって異なる可能性がある。
- 変更: exp025のレイアウト・曜日調整後の月次倍率を、店舗別から店舗・カテゴリ別に変更する。定番商品の数量相当売上から過去のみで算出し、算出不能時は倍率1とする。その他は変更しない。
- 検証: 2022〜2023年から2024年を一括予測。予測期間の予定が事前既知と仮定し、尺度は2022年平均による2023年の誤差から再計算。単一年での候補選択による過学習に注意する。
- 実行: `uv run python -m exp.exp026_category_season.run`

## 結果

- 2024年の6層正規化 RMSE: **0.396867**（exp025: 0.396673）。日次行 RMSE: **2,815.745円**。
