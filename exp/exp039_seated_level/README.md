# exp039: 着席組数の最新レイアウト水準

- 仮説: EDA 13では店舗売上の変化を着席組数と着席組当たり売上に分けて比較した。レイアウト変更後の客数水準を直接使うと売上による数量相当値より店舗需要を捉えられる可能性がある。
- 変更: exp032の店舗・カテゴリ・曜日別の最新レイアウト倍率を、来店ログから履歴の着席組数を集計した店舗・曜日別の最新レイアウト倍率に置き換える。直近年3倍、重み付き日数12未満や算出不能時は元の倍率を維持する。検証・テスト日の来店実績は前処理で結合しない。
- 検証: 2022〜2023年の来店履歴から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。着席組単価や商品の構成は変わらないと近似する。
- 実行: `uv run python -m exp.exp039_seated_level.run`

## 結果

- 2024年の6層正規化 RMSE: **0.424181**（exp032: 0.390239）。日次行 RMSE: **2,829.284円**。
