# exp064: 月別傾向を除いた最新レイアウト水準

- 仮説: EDA 08・13ではレイアウト変更前後に店舗水準が変化した。exp060の最新レイアウト平均は、年の途中の変更後に観測された月に偏るため、季節変動が水準差に混ざる可能性がある。
- 変更: exp060の最新レイアウト倍率を、履歴の店舗・月別季節倍率で数量相当売上を割った後に求めた倍率へ置き換える。季節倍率の作り方、直近年3倍、店舗・カテゴリ・曜日の集計単位、条件不足時の補完は基礎モデルと同じ。その他は変更しない。
- 検証: 2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。過去の月別変動が翌年も同じとは限らない。
- 実行: `uv run python -m exp.exp064_season_adjusted_layout.run`

## 結果

- 2024年の6層正規化 RMSE: **0.371475**（exp060: 0.372027）。日次行 RMSE: **2,773.625円**。
