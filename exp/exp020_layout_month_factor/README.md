# exp020: 最新レイアウト水準に月次倍率を追加

- 仮説: EDAでは店舗売上に季節的な変化が見られた。月次倍率はexp014では悪化したが、exp019のように店舗水準の変化を補正した後には有効となる可能性がある。
- 変更: exp019にexp014と同じ、過去の定番商品を価格で割った日別合計から曜日ごとの平均を除いた店舗・月別の平均倍率を掛ける。直近年は3倍重みとし、集計できない場合は倍率1とする。それ以外は変更しない。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp020_layout_month_factor.run`

## 結果

- 2024年の6層正規化 RMSE: **0.461224**（exp019: 0.432661）。日次行 RMSE: **2,895.351円**。

- 悪化したため採用しない。
