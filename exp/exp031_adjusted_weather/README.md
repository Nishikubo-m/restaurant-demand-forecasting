# exp031: レイアウト・月別水準を除いた天候別平均

- 仮説: EDA 10では雨日の比較に季節・店舗等による交絡が残る。exp030の雨・非雨別平均にはレイアウトや月の水準差が混ざっている可能性がある。
- 変更: exp030の過去の雨・非雨の売上平均を、店舗・カテゴリ・レイアウト・月・曜日の平均で正規化してから計算する。将来は引き続き降水確率平年値だけで混合する。条件不足時は倍率1。その他は変更しない。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。雨と売上の差は因果効果を示さない。
- 実行: `uv run python -m exp.exp031_adjusted_weather.run`

## 結果

- 2024年の6層正規化 RMSE: **0.392608**（exp030: 0.393119）。日次行 RMSE: **2,802.912円**。
- 層別正規化 RMSE: date_store_item **0.477246**、daily_store **0.576589**、daily_item **0.218242**、monthly_store_item **0.208889**、monthly_store **0.511264**、monthly_item **0.109409**。
