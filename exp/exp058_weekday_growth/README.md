# exp058: 曜日別の直近年次変化

- 仮説: EDA 01・10では曜日によって売上や客層が異なった。exp054の店舗全体の前年比は売上の大きい曜日が強く反映されるため、曜日別の変化を取り込む余地がある。
- 変更: exp054の直近3か月の店舗・レイアウト・非祝日の364日ペアから曜日別前年比も計算し、店舗全体の前年比と半分ずつ混ぜる。曜日別に2ペア以上必要で、不足時は元の店舗倍率を維持。予測期間に応じた外挿は同じ。
- 検証: 2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。曜日別の少数のペアには天候などの影響が残る。
- 実行: `uv run python -m exp.exp058_weekday_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.376655**（exp054: 0.374623）。日次行 RMSE: **2,781.374円**。
- 曜日別前年比を使用した検証行: 149,268行。
