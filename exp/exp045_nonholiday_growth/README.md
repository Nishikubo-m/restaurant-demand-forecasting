# exp045: 非祝日に限定した同一条件の年次変化

- 仮説: EDA 10では祝日に売上が変わる傾向があり、祝日の曜日配置は年によって異なる。exp042の年次比較には祝日構成の違いが混ざる可能性がある。
- 変更: exp042の同一店舗・レイアウト・月・曜日の前年比を、非祝日の履歴に限定して計算する。他の条件・前年変化の半分を反映する仮定は維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp045_nonholiday_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.383407**（exp042: 0.384175）。日次行 RMSE: **2,788.370円**。
- 層別正規化 RMSE: date_store_item **0.474770**、daily_store **0.562436**、daily_item **0.218925**、monthly_store_item **0.203434**、monthly_store **0.488510**、monthly_item **0.110951**。
