# exp027: 祝日前後の非祝日

- 仮説: EDA 10では祝日の影響に連休が交絡し得ると記載した。祝日の前後も旅行等の利用変化があり、通常の非祝日とは異なる可能性がある。
- 変更: exp025に、祝日前後3日以内かどうかで非祝日の店舗・曜日別の過去平均倍率を掛ける。店舗・レイアウト・月・曜日・祝日条件の過去平均で事前に正規化し、直近年3倍、重み付き日数5未満や欠損時は倍率1。祝日は既存の祝日補正を維持する。祝日配置は事前のカレンダーだけを使う。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。単一年での候補選択に注意する。
- 実行: `uv run python -m exp.exp027_near_holiday.run`

## 結果

- 2024年の6層正規化 RMSE: **0.397538**（exp025: 0.396673）。日次行 RMSE: **2,818.059円**。
