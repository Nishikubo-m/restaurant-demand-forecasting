# exp003: 共通処理による exp002 の再現

- 目的: `src/` に切り出した販売可能性、評価、実行管理が exp002 と同じ結果を出すことを確かめる。
- 方法: exp002 と同じ販売可能日の店舗×商品×曜日平均と補完順。新しい特徴量やモデルは追加しない。
- 検証: 2022〜2023年から2024年を一括予測し、2022年平均→2023年の誤差で尺度を作る。2024年の販売・企画予定が2023年末に既知という仮定を置く。
- 実行: `uv run python -m exp.exp003_shared_baseline.run`

## 結果

- 2024年の6層正規化 RMSE: **0.828145**、日×店舗×商品 RMSE: **3,495.942円**。
- exp002 と検証予測307,440行、2025年予測306,600行、各層の指標・補完件数が完全一致。
- 保存先: `output/runs/20261117_005952_266930_exp003_shared_baseline/`。
- スコアは2024年のローカル参考値であり、2025年の公式スコアではない。
- 共通CLIで変換した提出ファイルは公式スクリプトの形式検証に合格。検証時の日次予測は上記runとバイト単位で一致する。外部への提出は未実施。
