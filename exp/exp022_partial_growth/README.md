# exp022: 最新レイアウト水準への部分的な年次成長

- 仮説: EDA 13では来店組数と着席率の年次変化が店舗別に異なった。最新レイアウトでの観測水準に対して、直近年の成長率の一部が翌年にも続く可能性がある。
- 変更: exp021の予測に、定番商品の日平均数量相当の店舗別前年比の平方根を掛ける。前年比の全量を翌年へ外挿せず、対数変化の半分を事前仮定として反映する。履歴不足・非正値などでは倍率1。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。成長が翌年も続く保証はない。
- 実行: `uv run python -m exp.exp022_partial_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.471122**（exp021: 0.429323）。日次行 RMSE: **2,901.716円**。
