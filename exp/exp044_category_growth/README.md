# exp044: カテゴリ別の同一条件での年次変化

- 仮説: EDA 18では客層・時間帯によりカテゴリ構成が異なる。店舗全体に一律の年次変化を掛けるexp042より、カテゴリによる変化の違いが有用な可能性がある。
- 変更: exp042と同じ条件（店舗・レイアウト・月・曜日、各年2日以上）でカテゴリ別の定番商品数量相当値の前年比も求め、店舗別倍率と半分ずつ混合する。各倍率は年次変化の半分が続く仮定。カテゴリ別で計算できない場合は店舗別倍率を維持。
- 検証: 2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。前年比は因果効果ではない。
- 実行: `uv run python -m exp.exp044_category_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.384599**（exp042: 0.384175）。日次行 RMSE: **2,787.368円**。
