# exp049: カテゴリ別の364日ペア年次変化

- 仮説: EDA 18では客層・時間帯により商品カテゴリの構成が異なる。exp048の直近四半期の同曜日ペアにもカテゴリ別の変化がある可能性がある。
- 変更: exp048の店舗別の364日前ペアの前年比に、カテゴリ別・同一レイアウトの前年比を半分混合する。両日とも非祝日で14ペア以上が必要。カテゴリ別が不足する場合は店舗別を使い、予測期間に応じた外挿は維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。カテゴリ別の前年比に天候等の影響が残る。
- 実行: `uv run python -m exp.exp049_category_paired_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.374727**（exp048: 0.374623）。日次行 RMSE: **2,777.598円**。
