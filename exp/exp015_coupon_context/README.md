# exp015: クーポン予定の条件付き平均

- 仮説: EDAでは同一店舗・カテゴリでもクーポン予定のある日に実際の利用がみられたため、対象予定の有無で売上水準が異なる可能性がある。
- 変更: exp013に、履歴の店舗・商品カテゴリ・曜日別の売上数量相当の日平均に対する、クーポン予定の有無ごとの平均倍率を掛ける。予定は日付・店舗・対象商品群をカテゴリに照合し、複数予定は有無にまとめる。直近年は3倍重みとする。該当する重み付き日数が5未満、または平均が計算不能な場合は倍率1とする。
- 予定の一致はクーポン利用資格や利用実績ではなく、この倍率は施策の因果効果ではない。対象日が特定曜日等に偏る影響が残る。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp015_coupon_context.run`

## 結果

- 2024年の6層正規化 RMSE: **0.561457**（exp013: 0.562180）。日次行 RMSE: **3,026.369円**（exp013: 3,025.804円）。
- 層別正規化RMSE: 日×店舗×商品 **0.515294**、日×店舗 **0.789186**、日×商品 **0.240048**、月×店舗×商品 **0.302377**、月×店舗 **0.913566**、月×商品 **0.139295**。
- 検証行のうち476行は倍率を計算できず1を使用。改善は小さく、日次の行RMSEは微増したため安定性は未確認。
- 保存先: `output/runs/20261117_011507_231508_exp015_coupon_context/`。
