# exp024: レイアウト水準を除いた月次倍率

- 仮説: exp020の月次倍率はレイアウト変更前後の水準差を季節性として混同している可能性がある。EDA 08・13・17では店舗レイアウトに関連する水準変化が見られた。
- 変更: exp021に、定番商品の数量相当売上を過去の店舗・レイアウト・曜日別平均で割ってから、店舗・月別に集計した平均倍率を掛ける。直近年3倍で、算出できない場合は倍率1とする。レイアウト・曜日の正規化を加えた点以外はexp020の月次倍率と同じ。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp024_adjusted_month.run`

## 結果

- 2024年の6層正規化 RMSE: **0.401270**（exp021: 0.429323）。日次行 RMSE: **2,824.322円**。
- 保存先: `output/runs/20261117_012346_394317_exp024_adjusted_month/`。
- 水準差の調整前に月次倍率を加えたexp020より改善。2024年だけで比較しているため安定性は未確認。
