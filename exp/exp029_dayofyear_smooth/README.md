# exp029: 日付近傍の平滑化平均

- 仮説: EDA 01・14では売上の季節変動・前年付近の反復性が見られた。月別倍率より短い共通の季節変動を、全店舗の過去をまとめることで捉えられる可能性がある。
- 変更: exp025に、過去の定番商品の数量相当の日次合計を店舗・レイアウト・月・曜日・祝日別平均で正規化してから、月日を揃え、全店舗の15日移動平均を倍率として掛ける。履歴の直近年は3倍。年末年始は循環し、閏日は共通の閏年カレンダーに整列する。算出できない場合は倍率1。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。前年までの季節変動が続く保証はない。
- 実行: `uv run python -m exp.exp029_dayofyear_smooth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.393254**（exp025: 0.396673）。日次行 RMSE: **2,804.564円**。
- 層別の正規化 RMSE: date_store_item **0.477528**、daily_store **0.577938**、daily_item **0.218180**、monthly_store_item **0.209309**、monthly_store **0.512195**、monthly_item **0.109961**。
- 保存先: `output/runs/20261117_014919_532150_exp029_dayofyear_smooth/`。2024年だけで比較しており、安定性は未確認。
