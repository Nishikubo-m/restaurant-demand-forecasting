# exp038: 祝日水準を除いた月次倍率

- 仮説: EDA 10では祝日と非祝日の売上差が店舗・曜日ごとに異なる。exp032の月次倍率には祝日が多い月の影響が入り、別途祝日倍率を掛けることで影響が重なる可能性がある。
- 変更: exp032の月次倍率の基準平均を、店舗・レイアウト・曜日別から店舗・レイアウト・曜日・祝日有無別に変更する。月次倍率は両状態の日を用いて集計し、直近年3倍や他の補正は維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp038_month_nonholiday.run`

## 結果

- 2024年の6層正規化 RMSE: **0.390898**（exp032: 0.390239）。日次行 RMSE: **2,798.662円**。
