# exp009: 店舗・商品カテゴリ・曜日別の祝日倍率

- 仮説: EDAで客層・店舗・曜日によって商品カテゴリの構成が異なり、祝日の影響もカテゴリで異なる可能性がある。
- 変更: exp008の祝日倍率の集計単位を「店舗×曜日」から「店舗×カテゴリ×曜日」に変更する。それ以外の価格正規化・直近年重み・店舗年次変化・平均予測は維持する。
- 検証: 2022〜2023年から2024年を一括予測。2024年の価格・販売・企画予定が2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp009_category_holiday.run`

## 結果

- 2024年の6層正規化 RMSE: **0.593219**（exp008: 0.593427）。日次行RMSE: **3,056.382円**。
- 保存先: `output/runs/20261117_010823_503313_exp009_category_holiday/`。
- 改善は小さく、祝日ごとのサンプル数も少ないため、別期間での安定性は未確認。
