# exp004: 直近年の履歴に重みを付ける

- 仮説: EDAで店舗別の年次変化が確認されたため、直近年をより重視すると水準変化への追随が改善する。
- 変更: exp003の販売可能日・店舗×商品×曜日の平均と補完順を維持し、基準日前の直近暦年の観測を3倍に重み付けする。他年は1倍。行の複製で同じ加重平均を計算する。
- 検証: 2022〜2023年から2024年を一括予測。2024年の販売・企画予定は2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp004_recent_weight.run`

## 結果

- 2024年の6層正規化 RMSE: **0.757162**（exp003: 0.828145）。日次行RMSE: **3,373.844円**。
- 層別正規化RMSE: 日×店舗×商品 0.574458、日×店舗 1.054773、日×商品 0.317240、月×店舗×商品 0.399662、月×店舗 1.296680、月×商品 0.235515。
- 保存先: `output/runs/20261117_010428_251859_exp004_recent_weight/`。
- ローカル検証値であり公式スコアではない。直近年重みの3倍は仮説上の固定値で、2024年以外での安定性は未確認。
