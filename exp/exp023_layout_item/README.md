# exp023: 最新レイアウトの商品別水準

- 仮説: EDA 18では客層・時間帯ごとの商品構成が異なる。最新レイアウトにおける変化は同じカテゴリ内の商品ごとにも異なる可能性がある。
- 変更: exp021の店舗・カテゴリ・曜日別のレイアウト水準倍率を、履歴が足りる店舗・商品・曜日では商品別倍率に置き換える。定番以外も販売可能な履歴だけを使い、直近年3倍、最新レイアウトの重み付き日数12未満やゼロ割り等の際にはカテゴリ別倍率を維持する。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。レイアウト前後の差は因果効果を意味しない。
- 実行: `uv run python -m exp.exp023_layout_item.run`

## 結果

- 2024年の6層正規化 RMSE: **0.432513**（exp021: 0.429323）。日次行 RMSE: **2,897.108円**。
- 保存先: `output/runs/20261117_012311_154825_exp023_layout_item/`。
- 悪化したため採用しない。商品ごとの履歴が短くばらつきが大きい可能性がある。
