# exp055: 基準日に合わせた直近3か月の参考検証

- 目的: exp054と基礎モデルexp040を、2023年6月末を基準日として比較する。exp053と尺度・対象期間・予定情報の仮定は同じ。
- 検証: 2022年〜2023年6月を履歴、2023年7〜12月を予測。2023年後半の予定は6月末に既知と仮定。尺度は2022年前半平均から同年後半を予測した誤差で、2024年通年・公式スコアとは直接比較できない。
- 過去のEDAにも含まれた期間であり、完全に未使用の評価データではない。
- 実行: `uv run python -m exp.exp055_rolling_backtest.run`

## 結果

- 2023年7〜12月の参考6層スコア: exp040 **0.834779**、exp054 **0.817298**。exp048の参考値は **0.816387**。
- exp054で前年同曜日ペアによる直近3か月の補正を使用した店舗: **10店舗**。
- 保存先: `output/runs/20261117_022201_985389_exp055_rolling_backtest/`。基礎モデルより改善したが、固定期間のexp048よりわずかに悪化した。
