# exp013: 価格上昇時の数量減を仮定した平均予測

- 仮説: EDAの価格変更前後の数量減を受け、値上げ時に販売数量が減る可能性を考える。
- 変更: exp012の予測に `(過去の販売可能日の平均価格 / 対象日の価格) ** 0.5` を掛ける。基準価格は店舗・商品別で、直近年を3倍重みとし、欠損時は商品別、全体の順に補完する。それ以外は変更しない。
- 係数0.5は検証前に置いた仮定で、価格弾力性を履歴から推定したものではない。需要量と価格変更の因果関係も確認できていない。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。価格などの予定は事前既知と仮定。スケールは2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp013_price_elasticity.run`

## 結果

- 2024年の6層正規化RMSE: **0.562180**（exp012: 0.593219）。日次行RMSE: **3,025.804円**。
- 保存先: `output/runs/20261117_011249_946463_exp013_price_elasticity/`。
- 2024年で改善したが、別期間における安定性と価格弾力性の仮定は未検証。
