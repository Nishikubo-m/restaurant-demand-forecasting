# exp047: 予測期間の経過に応じた年次変化

- 仮説: EDA 13では店舗ごとの年次変化が観察された。exp046は1年分の予測日に同じ半分の変化を掛けるが、基準日から離れるほど変化が積み重なる可能性がある。
- 変更: exp046で計算した前年同条件比について、対数変化に掛ける割合を固定の0.5から `(予測日 - 履歴最終日) / 365`（0〜1に制限）に変更する。1年間同じ割合の変化が続く事前仮定であり、予測対象日の実績は使わない。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。変化が一定で続く保証はない。
- 実行: `uv run python -m exp.exp047_horizon_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.374720**（exp046: 0.376520）。日次行 RMSE: **2,778.170円**。
- 層別正規化 RMSE: date_store_item **0.473034**、daily_store **0.551742**、daily_item **0.218336**、monthly_store_item **0.198407**、monthly_store **0.464001**、monthly_item **0.109441**。
