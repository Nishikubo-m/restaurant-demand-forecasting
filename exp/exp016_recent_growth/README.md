# exp016: 直近四半期の店舗成長率

- 仮説: EDAでは店舗ごとに年間の成長や構造変化が異なる。年間平均に比べ、直近四半期の前年同期比は予測開始時点の傾向を反映しやすい可能性がある。
- 変更: exp015の店舗別前年比を、定番商品の数量相当の日平均について、直近年10〜12月とその前年同月の比率に置き換える。その他の予測処理は変えない。計算できない店舗では元の年間前年比を使う。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。10〜12月の変化が通年に続く保証はない。
- 実行: `uv run python -m exp.exp016_recent_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.592629**（exp015: 0.561457）。日次行 RMSE: **3,082.357円**。

- 年間前年比を使う方法より悪化したため採用しない。
