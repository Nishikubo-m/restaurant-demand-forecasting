# exp017: 前年近傍の同曜日平均

- 仮説: EDA 14では店舗売上に前年同曜日付近の反復性が見られた。前年の同時期に限定した平均が季節や緩やかな変化を捉える可能性がある。
- 変更: exp015に、前年の定番商品について価格で割った日別合計を店舗×曜日の年平均で割り、予測日の350・357・364・371・378日前の同曜日の平均を求める。利用可能な過去日が2日以上なら、その倍率と1の平均を掛ける。平均を安定させるため祝日は集計から除き、過去しか参照しない。不足時は倍率1。
- 350日前等も予測基準日以後のデータは履歴にないため自動的に除外される。過去の天候や祝日の配置が翌年と一致する保証はなく、0.5の混合率は検証前の仮定。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp017_near_year_mean.run`

## 結果

- 2024年の6層正規化 RMSE: **0.570941**（exp015: 0.561457）。日次行 RMSE: **3,046.190円**。

- 悪化したため採用しない。前年近傍の偶然の変動が残った可能性がある。
