# exp019: 最新レイアウト時の店舗水準

- 仮説: EDA 08・13・17では席構成の変更や着席率・店舗売上の変化が見られる。予測時点のレイアウトで観測された店舗水準を使うと、過去の構成を含む年平均より現状を捉えられる可能性がある。
- 変更: exp018の店舗別年間成長率を取り除き、定番商品の数量相当売上について、観測済み最新レイアウト時の曜日別平均と、重み付き履歴全体の曜日別平均の比率に置き換える。過去の直近年3倍は維持する。重み付き日数12未満などで計算できない場合は元の年間成長率を使う。将来の新レイアウトの影響は推定しない。
- 実績は基準日以前に限る。レイアウトの変更と需要水準の変化に因果関係があるとは限らず、直近期間の天候や季節に左右される。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp019_latest_layout_level.run`

## 結果

- 2024年の6層正規化 RMSE: **0.432661**（exp018: 0.560128）。日次行 RMSE: **2,854.178円**。
- 層別の正規化RMSE: 日×店舗×商品 **0.48598**、日×店舗 **0.63137**、日×商品 **0.23971**、月×店舗×商品 **0.22764**、月×店舗 **0.59986**、月×商品 **0.13879**。
- 保存先: `output/runs/20261117_011950_698425_exp019_latest_layout_level/`。
- レイアウト変更後の観測期間が短い店舗もある。2024年のみの改善であり、別期間での安定性は未確認。
