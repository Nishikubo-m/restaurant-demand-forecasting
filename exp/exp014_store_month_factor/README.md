# exp014: 店舗別の月次季節性

- 仮説: EDAで月次の売上が季節により変わることから、商品単位よりもサンプルが多い店舗単位で季節性を捉える。
- 変更: exp013に、過去の定番商品を価格で割った日別合計から曜日ごとの平均を除いた、店舗・月別の平均倍率を掛ける。直近年の各日には3倍の重みを付ける。集計できない場合は倍率1とする。商品別月次倍率のexp007とは集計単位が異なる。
- 検証: 2022〜2023年を履歴、2024年を予測する。価格などの予定は事前既知と仮定し、2022年平均による2023年の誤差から評価尺度を作る。
- 実行: `uv run python -m exp.exp014_store_month_factor.run`

## 結果

- 2024年の6層正規化 RMSE: **0.591725**（exp013: 0.562180）。日次行 RMSE: **3,075.767円**。
- 保存先: `output/runs/20261117_011417_808837_exp014_store_month_factor/`。
- 悪化したため採用しない。2022〜2023年の月次変動が2024年も再現するとは限らない。
