# exp053: 2023年後半の参考検証

- 目的: 2024年の通年検証で選ばれたexp048と、その基礎のexp040を、より前の予測基準日でも比較する。モデルは変更しない。
- 検証: 2022年〜2023年6月を履歴に、2023年7〜12月を一括予測。2023年後半の販売・価格・企画予定が2023年6月末に既知との仮定を置く。予測対象の実績売上・同日の天候実績はモデルに渡さない。
- 参考尺度: 2022年1〜6月の店舗・商品別日平均で2022年7〜12月を予測した6層RMSEを使う。2023年の正解は尺度に使用しない。これは公式の前年通年平均による尺度と異なり、2024年通年や公式スコアとの直接比較はできない。
- この期間は予測期間が6か月で、2024年の実験設計前のEDAに含まれるため、完全に未使用の評価セットでもない。参考診断として扱う。
- 実行: `uv run python -m exp.exp053_2023_backtest.run`

## 結果

- 2023年7〜12月の参考6層スコア: exp040 **0.834779**、exp048 **0.816387**。日次行 RMSE はそれぞれ **2,595.869円**、**2,590.339円**。
- exp048の前年同曜日ペアによる直近四半期の補正は **0店舗**。直近四半期部分はこの検証では評価できない。
