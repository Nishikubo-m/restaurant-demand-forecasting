# exp032: レイアウトの水準差を除いた祝日倍率

- 仮説: EDA 08・10はレイアウト前後の水準差と祝日比較の交絡を示している。exp031の祝日・非祝日倍率には、レイアウト変更前後の水準差が混ざる可能性がある。
- 変更: exp031の祝日・非祝日倍率を、過去の店舗・カテゴリ・曜日・レイアウト別平均で正規化した条件付き平均に置き換える。直近年を3倍とし、算出不能時は元の倍率を維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp032_adjusted_holiday.run`

## 結果

- 2024年の6層正規化 RMSE: **0.390239**（exp031: 0.392608）。日次行 RMSE: **2,797.261円**。
- 層別正規化 RMSE: date_store_item **0.476284**、daily_store **0.570430**、daily_item **0.218242**、monthly_store_item **0.208226**、monthly_store **0.508495**、monthly_item **0.109220**。
- 保存先: `output/runs/20261117_015343_991071_exp032_adjusted_holiday/`。2024年のみの評価であり、別期間での安定性は未確認。
