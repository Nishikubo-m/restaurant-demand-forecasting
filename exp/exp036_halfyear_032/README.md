# exp036_halfyear_032: 2024年後半の参考検証

- 目的: exp032_adjusted_holiday と同じ平均モデルを使い、2024年6月末までの履歴から7〜12月を予測する。2024年全体の一括予測とは予測時点・期間が異なり、主スコアとは直接比較できない。
- 尺度: 2022年平均による2023年誤差。2024年後半の計画情報は6月末に既知と仮定する。
- 実行: `uv run python -m exp.exp036_halfyear_032.run`

## 結果

- 2024年7〜12月の6層正規化 RMSE: **0.332109**。日次行 RMSE: **2,733.867円**。
- 保存先: `output/runs/20261117_015804_660286_exp036_halfyear_032/`。
- この期間は主検証の2024年に含まれており独立した未使用期間ではない。また半年先予測で、目標とする2024年通年一括予測のスコアではない。
