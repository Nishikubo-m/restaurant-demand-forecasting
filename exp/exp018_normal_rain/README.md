# exp018: 降水確率平年値による雨・非雨の平均

- 仮説: EDA 10で同じ店舗・年・月・曜日内の雨日と晴日の売上に差が見られたため、将来の降水確率平年値によって売上期待値が変わる可能性がある。
- 変更: exp015の予測に、履歴中の雨日・非雨日の店舗×カテゴリ×曜日別の数量相当売上平均を、将来の日の降水確率平年値で加重平均した値と、履歴全体の平均の比を掛ける。履歴は直近年3倍、両条件の重み付き日数が5未満、または倍率が非有限なら1にする。
- 将来は平年値だけを使い、予測対象日の天候実績は読み込まない。平年値は当日の天気予報ではない。履歴の雨・非雨差には交絡があり、因果効果ではない。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp018_normal_rain.run`

## 結果

- 2024年の6層正規化 RMSE: **0.560128**（exp015: 0.561457）。日次行 RMSE: **3,025.004円**。
