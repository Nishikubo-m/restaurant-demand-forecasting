# exp066: 極端値候補の影響を抑える感度分析

- 仮説: EDA 22では売上の同一年・店舗・商品・曜日の中央値が正の行の中に10倍超の候補があった。入力ミスと断定できないが、単純平均が候補値の影響を受ける可能性がある。
- 変更: exp064の予測に渡す履歴だけで、同一年・店舗・商品・曜日の中央値が正の場合に売上をその10倍で上限化する。閾値は事前固定。元データと検証・テストの実績は変更せず、予測対象期間を使って中央値を算出しない。中央値0の行には適用しない。
- 検証: 2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は変更前の2022年平均による2023年誤差。正当な需要のピークも抑える可能性がある。
- 実行: `uv run python -m exp.exp066_robust_history.run`

## 結果

- 2024年の6層正規化 RMSE: **0.371478**（exp064: 0.371475）。日次行 RMSE: **2,773.623円**。
- 履歴で上限化された行: **4行**。テスト予測時の履歴は **5行**。
