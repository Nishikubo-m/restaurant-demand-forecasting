# exp006: 価格正規化した平均

- 仮説: EDAで2024年と2025年に価格改定が確認された。過去の売上をその日の割引前価格で割り、対象日の予定価格を掛けると、水準変化を反映できる可能性がある。
- 変更: exp005の予測モデル・直近年重み・祝日倍率を維持し、平均する対象だけを `sales_amount / selling_price` に変える。得られた平均に予測日の既知の予定価格を掛ける。これは厳密な販売数量ではなく、値引きの影響を含む数量相当値。
- 検証: 2022〜2023年のデータから2024年を予測。2024年の価格・販売・企画予定が2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp006_price_normalization.run`

## 結果

- 2024年の6層正規化 RMSE: **0.626834**（exp005: 0.741816）。日次行RMSE: **3,114.197円**。

- ローカル検証値であり公式スコアではない。価格に応じた数量変化は考慮していない。
