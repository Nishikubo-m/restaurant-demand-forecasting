# exp046: 直近四半期の同一条件の年次変化

- 仮説: EDA 13では店舗ごとに来店と着席率の年次変化が異なる。exp045の年間を通じた変化より、予測開始時点に近い期間の変化が現状を捉える可能性がある。
- 変更: exp045の同一店舗・レイアウト・月・曜日の非祝日前年比を、直近年の10〜12月の条件に限定する。条件がない店舗はexp045と同じ年間の倍率を使う。年次変化の半分が続くという仮定やその他の補正は同じ。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。直近の変化が続く保証はない。
- 実行: `uv run python -m exp.exp046_recent_matched_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.376520**（exp045: 0.383407）。日次行 RMSE: **2,780.120円**。
- 直近四半期の前年比を利用できた店舗: 5店舗。
