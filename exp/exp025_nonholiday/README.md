# exp025: 非祝日の条件付き平均

- 仮説: EDA 10では祝日と非祝日で売上が異なる。基準の曜日別平均には祝日も含まれるため、祝日だけでなく非祝日も条件付き平均へ補正すると整合的になる可能性がある。
- 変更: exp024に、予測日が非祝日の場合のみ、過去の店舗・カテゴリ・曜日別の非祝日売上平均を同じ曜日の全日平均で割った倍率を掛ける。既存の祝日倍率と同じ集計と直近年3倍の重みを使い、算出できない場合は倍率1とする。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。
- 実行: `uv run python -m exp.exp025_nonholiday.run`

## 結果

- 2024年の6層正規化 RMSE: **0.396673**（exp024: 0.401270）。日次行 RMSE: **2,816.097円**。
- 層別正規化RMSE: date_store_item **0.479491**、daily_store **0.589457**、daily_item **0.224831**、monthly_store_item **0.208788**、monthly_store **0.510543**、monthly_item **0.109216**。
- 保存先: `output/runs/20261117_012421_696684_exp025_nonholiday/`。再実行 `output/runs/20261117_012435_676753_exp025_nonholiday/` と検証・テスト予測の全行、評価結果が一致した。
- 2024年の予定情報が2023年末に既知という仮定がある。同じ検証年で多数の仮説を比較しており、別期間や公式スコアでの再現性は未確認。
