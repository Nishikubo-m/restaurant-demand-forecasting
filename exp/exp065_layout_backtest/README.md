# exp065: 季節調整したレイアウト水準の参考検証

- 目的: exp064の月別傾向を除いたレイアウト水準を、2023年6月末を基準とする別時点でも診断する。
- 検証: 2022年〜2023年6月を履歴に、2023年7〜12月を一括予測。後半の予定が6月末に既知と仮定。尺度は2022年前半の日平均から同年後半を予測した6層誤差。2024年通年・公式スコアとは直接比較できない。
- 過去のEDAに含まれた期間であり完全に未使用の評価データではない。2023年6月時点では直近年が部分年である。
- 実行: `uv run python -m exp.exp065_layout_backtest.run`

## 結果

- 2023年7〜12月の参考6層スコア: exp064 **0.807691**、exp040 **0.834779**。同条件のexp060は **0.811133**。
- exp064の日次行 RMSE: **2,588.354円**。
