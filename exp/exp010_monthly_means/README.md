# exp010: 月・曜日別の過去平均

- 仮説: EDAで月ごとの店舗・カテゴリの売上水準が変わり、exp007の全店舗の商品別月倍率だけでは改善しなかった。店舗ごとの季節パターンを直接比較する。
- 変更: exp009の価格正規化した平均を「店舗×商品×月×曜日」の販売可能日平均に変更する。未観測の組み合わせは元の店舗×商品×曜日、店舗×商品、商品、全体に順次フォールバック。平均ベースのモデルと他の補正は維持する。
- 検証: 2022〜2023年から2024年を一括予測。2024年の価格・販売・企画予定が2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp010_monthly_means.run`

## 結果

- 2024年の6層正規化 RMSE: **0.641097**（exp009: 0.593219）。日次行RMSE: **3,245.150円**。
