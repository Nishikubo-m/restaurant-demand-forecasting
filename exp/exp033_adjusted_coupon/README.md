# exp033: レイアウトの水準差を除いた施策倍率

- 仮説: EDA 10・21に記載のとおり施策予定と売上の差には交絡がある。店舗のレイアウト変更もその一因になり得る。
- 変更: exp032のクーポン予定の有無による過去の条件付き平均を、店舗・カテゴリ・レイアウト・曜日別平均で正規化してから計算する。直近年3倍、条件不足なら倍率1。実際の利用・因果効果を推定するものではない。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp033_adjusted_coupon.run`

## 結果

- 2024年の6層正規化 RMSE: **0.390396**（exp032: 0.390239）。日次行 RMSE: **2,797.772円**。
