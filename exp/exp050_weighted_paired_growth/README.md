# exp050: 直近四半期を重視した通年の364日ペア

- 仮説: EDA 14では364日前の同曜日に一定の反復性が見られた。exp048は直近四半期だけのペアが不足すると利用できないが、通年の履歴を使えばより多くの店舗で変化を推定できる可能性がある。
- 変更: exp048の同一店舗・レイアウト・非祝日の364日ペアについて、直近年の通年を対象にし、10〜12月のペアを3倍重みとする。14ペア未満なら従来どおりexp047の前年比へ戻す。予測期間に応じた外挿は維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。季節・天候や店舗の変化による交絡は残る。
- 実行: `uv run python -m exp.exp050_weighted_paired_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.385467**（exp048: 0.374623）。日次行 RMSE: **2,790.882円**。
- 14ペア以上を確保できた店舗は 10店舗。
