# exp041: 予定されたレイアウト変更

- 仮説: EDA 08・17では席構成の変更前後で着席・離脱の変化が見られた。予測期間中の既知のレイアウト変更が水準に関係する可能性がある。
- 変更: exp040に、履歴のレイアウト変更前後28日の定番商品数量相当平均の比を、前年同曜日の同期間比で割り、過去の変更イベントの中央値を求める。予測期間のレイアウトが予測時点の最新履歴と異なる店舗・日だけにこの倍率を掛ける。十分な過去期間がないイベントは除外し、該当イベントがなければ倍率1とする。
- 変更予定は事前配布情報と仮定する。実際の将来の来店や売上は使わない。前後差は季節や同時期の他の要因が残り、因果効果ではない。
- 検証: 2022〜2023年を履歴、2024年を一括予測。尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp041_planned_layout.run`

## 結果

- 2024年の6層正規化 RMSE: **0.466053**（exp040: 0.390239）。日次行 RMSE: **2,888.711円**。
- 履歴の比較可能な変更 7件から求めた倍率は **1.1143**。検証期間の適用対象は 51,492 行。
- 保存先: `output/runs/20261117_020403_748119_exp041_planned_layout/`。悪化したため採用しない。レイアウトの種類や店舗の違いを一律の倍率で扱う限界がある。
