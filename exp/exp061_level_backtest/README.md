# exp061: 直近水準補正の2023年後半参考検証

- 目的: exp060の直近水準補正が、2024年通年だけでなく別の基準日においても参考になるか調べる。
- 検証: 2022年〜2023年6月を履歴、2023年7〜12月を予測。2023年後半の予定が6月末に既知と仮定。尺度は2022年前半の日平均から同年後半を予測した6層誤差。2024年通年や公式スコアとは直接比較できない。
- この期間は過去のEDAにも含まれており完全に未使用の評価データではない。過去時点での直近年が部分年であるため、通年学習時との違いにも注意する。
- 実行: `uv run python -m exp.exp061_level_backtest.run`

## 結果

- 2023年7〜12月の参考6層スコア: exp060 **0.811133**、exp040 **0.834779**。exp054の同条件の参考値は **0.817298**。
- exp060の日次行 RMSE は **2,588.716円**。
