# exp028: 祝日ごとの条件付き平均

- 仮説: EDA 01・10では祝日別・季節別の売上に差が見られた。2022〜2023年の店舗別・年別・月別・曜日別平均に対する売上を確認すると、5月3〜5日などは両年とも高い水準だった。祝日を一律に扱うと、祝日ごとの違いを見落とす可能性がある。
- 変更: exp025に、履歴の同じ月日の祝日売上を当該曜日の非祝日平均で割った倍率と、その曜日の全祝日平均倍率の比を掛ける。店舗・カテゴリ別で、日付一致がない移動祝日等は既存倍率を維持。履歴の直近年を3倍、サンプルが少ないため倍率と1を半分ずつ混合する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。祝日の種類を月日で近似し、他の条件の違いは残る。
- 実行: `uv run python -m exp.exp028_holiday_date.run`

## 結果

- 2024年の6層正規化 RMSE: **0.399902**（exp025: 0.396673）。日次行 RMSE: **2,828.629円**。
