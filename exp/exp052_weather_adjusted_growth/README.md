# exp052: 過去の天候構成を調整した前年比

- 仮説: EDA 10では雨日と非雨日の売上に差がある。exp048の前年比には、ペアとなる過去日の天候構成の違いが混ざる可能性がある。
- 変更: exp048の前年比に用いる過去の日別数量相当値を、過去の店舗別・雨非雨別の平均倍率で割る。倍率は同一店舗・レイアウト・月・曜日で正規化した過去の平均から算出し、各状態が14日未満などの場合は1。その他は変えない。
- 検証: 2022〜2023年を履歴、2024年を一括予測。天候実績は履歴のみを使用し、予測日には平年値だけを使う。尺度は2022年平均による2023年誤差。観測上の雨日差は因果効果ではない。
- 実行: `uv run python -m exp.exp052_weather_adjusted_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.375012**（exp048: 0.374623）。日次行 RMSE: **2,778.543円**。
