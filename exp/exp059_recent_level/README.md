# exp059: 重み付き履歴平均から直近水準への補正

- 仮説: EDA 13では店舗ごとに年次の水準変化が異なる。exp054の店舗・商品・曜日平均には直近年3倍・それ以前1倍で古い履歴が含まれるため、基準日時点の水準とずれる可能性がある。
- 変更: exp054の非祝日・同一レイアウトの364日ペアの前年比 `r` を使い、前年比を持つ店舗の予測に `(n + 3) * r / (n + 3 * r)` を掛ける。`n` は直近年より前の履歴年数。古い各年を直前年と同じ水準と近似し、直近年3倍・それ以前1倍の平均を直近年へ合わせる。ペア不足時は補正1。予測開始後の成長率は従来どおり。
- 実際の商品別・曜日別の履歴構成やレイアウト別補正は異なり、一律の近似は成立しない可能性がある。検証は2022〜2023年を履歴に2024年を一括予測し、尺度は2022年平均による2023年誤差。
- 実行: `uv run python -m exp.exp059_recent_level.run`

## 結果

- 2024年の6層正規化 RMSE: **0.374501**（exp054: 0.374623）。日次行 RMSE: **2,777.817円**。
- 履歴ペアがなく補正しなかった検証行: 184,464行。
