# exp021: 最新レイアウトの店舗・カテゴリ別水準

- 仮説: EDA 18では客層や時間帯で商品構成が異なる。席構成変更に伴う客層・利用形態の変化もカテゴリごとに異なる可能性がある。
- 変更: exp019の最新レイアウト時と履歴全体の数量相当売上の比率を、店舗・曜日別から店舗・カテゴリ・曜日別に変更する。カテゴリに定番商品の履歴がない等の理由で算出できない場合は、exp019同様、元の年間成長率を使う。
- 検証: 2022〜2023年を履歴、2024年を一括予測する。予定情報は事前既知と仮定し、尺度は2022年平均による2023年の誤差から算出する。レイアウト前後の差は因果効果を意味しない。
- 実行: `uv run python -m exp.exp021_layout_category.run`

## 結果

- 2024年の6層正規化 RMSE: **0.429323**（exp019: 0.432661）。日次行 RMSE: **2,854.960円**（exp019: 2,854.178円）。
- 層別の正規化 RMSE: date_store_item **0.486108**、daily_store **0.627291**、daily_item **0.236507**、monthly_store_item **0.227521**、monthly_store **0.592336**、monthly_item **0.132475**。
