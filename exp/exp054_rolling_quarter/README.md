# exp054: 基準日に合わせた直近3か月

- 目的: exp048の直近四半期が10〜12月固定で、年末以外の基準日では直近の履歴を使えない点を修正する。
- 変更: exp048の直近四半期を、履歴最終月とその前2か月に変更する。年末基準では従来と同じ10〜12月で、他のモデルや条件は維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。別時点の参考検証はexp055で確認する。
- 実行: `uv run python -m exp.exp054_rolling_quarter.run`

## 結果

- 2024年の6層正規化 RMSE: **0.374623**。exp048の検証・テスト予測の全行および評価結果と一致。
