# exp060: 直近水準補正の年間比較への補完

- 仮説: EDA 13では店舗別の水準変化が異なる。exp059は直近3か月の同曜日ペアが14日未満の店舗には水準補正を適用しておらず、比較可能な他の期間の情報を使える可能性がある。
- 変更: exp059の重み付き履歴平均から直近水準への補正に使う前年比を、直近ペア不足時にはexp059が予測成長率の補完に使っている同一レイアウト・月・曜日の前年比へ戻す。その他は変更しない。
- 検証: 2022〜2023年を履歴に2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。古い年が同じ水準という近似や季節・レイアウト変更の影響に注意する。
- 実行: `uv run python -m exp.exp060_fallback_level.run`

## 結果

- 2024年の6層正規化 RMSE: **0.372027**（exp059: 0.374501）。日次行 RMSE: **2,774.449円**。
