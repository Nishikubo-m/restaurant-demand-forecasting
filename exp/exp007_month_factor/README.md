# exp007: 商品別の月間季節倍率

- 仮説: EDAで月ごとの需要の違いが見られた。商品別の販売可能日に限った過去の月平均を使うことで季節差を反映できる可能性がある。
- 変更: exp006の価格正規化・祝日・直近年重み付き平均に、商品別の「販売可能日の月平均 / 通年平均」（数量相当値）を掛ける。対象月の過去例がない場合は1とする。平均ベースのモデルは変更しない。
- 検証: 2022〜2023年から2024年を一括予測。2024年の価格・販売・企画予定が2023年末に既知と仮定。2022年平均→2023年の6層誤差で尺度を計算する。
- 実行: `uv run python -m exp.exp007_month_factor.run`

## 結果

- 2024年の6層正規化 RMSE: **0.632723**（exp006: 0.626834）。日次行RMSE: **3,108.252円**。
- 保存先: `output/runs/20261117_010705_384599_exp007_month_factor/`。
- 6層スコアは悪化したため次の基準には採用しない。日次行RMSEだけでは全体指標の改善を意味しない。
