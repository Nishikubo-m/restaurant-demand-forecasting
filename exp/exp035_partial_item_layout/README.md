# exp035: 商品別レイアウト水準の部分的な反映

- 仮説: EDA 18では客層や時間帯で商品構成が異なる。exp023では商品別の最新レイアウト倍率に完全に置き換えると悪化したが、商品別の変化をカテゴリ平均に部分的に混合するとばらつきを抑えられる可能性がある。
- 変更: exp032のカテゴリ別レイアウト倍率に対し、商品別倍率との比を求め、1と半分ずつ混合して掛ける。販売可能な履歴を使い、直近年3倍、重み付き日数不足・欠損・非正値はカテゴリ倍率を維持。その他の変更はしない。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。商品別の前後差は因果効果を意味しない。
- 実行: `uv run python -m exp.exp035_partial_item_layout.run`

## 結果

- 2024年の6層正規化 RMSE: **0.391715**（exp032: 0.390239）。日次行 RMSE: **2,808.502円**。
