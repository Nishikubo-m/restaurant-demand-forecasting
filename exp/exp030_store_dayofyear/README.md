# exp030: 店舗別の日付近傍平均

- 仮説: EDA 01・10・14では店舗によって季節性や来店傾向が異なった。月内の変動も店舗によって違う可能性がある。
- 変更: exp029の15日移動平均を店舗別にも算出し、全店舗平均と半分ずつ混合する。正規化・直近年3倍・年末年始の循環はexp029と同じ。店舗別平均が不安定になることを考慮した固定の混合率であり、欠損時は1とする。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。単一年での候補選択に注意する。
- 実行: `uv run python -m exp.exp030_store_dayofyear.run`

## 結果

- 2024年の6層正規化 RMSE: **0.393119**（exp029: 0.393254）。日次行 RMSE: **2,803.587円**。
