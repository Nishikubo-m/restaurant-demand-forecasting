# exp034: 価格上昇と数量減が相殺する仮定

- 仮説: EDA 08では価格改定前後で定番商品の数量が減った例がある。exp032の「価格変化率の半分だけ数量が逆方向に変わる」仮定より反応が強い場合を検討する。
- 変更: exp032で価格による予測額の変化が数量変化で相殺される（数量の価格弾力性を一律 -1 とする）仮定に置き換える。定価に対する数量変化の因果推定ではなく、検証前に置いた感度分析上の仮定。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。過去2年間に定価変更がなく弾力性を推定できない点に注意する。
- 実行: `uv run python -m exp.exp034_unit_elasticity.run`

## 結果

- 2024年の6層正規化 RMSE: **0.430591**（exp032: 0.390239）。日次行 RMSE: **2,855.095円**。
- 保存先: `output/runs/20261117_015604_755330_exp034_unit_elasticity/`。
- 悪化したため採用しない。2024年単独の結果から価格弾力性の実値を断定できない。
