# exp048: 364日前を対応付けた年次変化

- 仮説: EDA 14では364日前は同じ曜日になる。exp047の直近四半期の前年同条件比は月内の曜日平均どうしだが、個々の日と前年同曜日を対応付けると月境界や祝日配置の差を減らせる可能性がある。
- 変更: exp047の直近四半期の前年比を、同じ店舗・レイアウトかつ両日とも非祝日の364日差ペアの数量相当売上合計の比に置き換える。14ペア以上ある店舗で使用し、足りなければexp047の前年比を維持。予測期間に応じた外挿は維持する。
- 検証: 2022〜2023年から2024年を一括予測。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。前年比には天候などの影響も残る。
- 実行: `uv run python -m exp.exp048_paired_growth.run`
