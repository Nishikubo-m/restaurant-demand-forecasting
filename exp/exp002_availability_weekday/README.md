# exp002: 販売可能性を考慮した曜日別平均

- 目的: 販売期間外・コラボ企画の非参加店舗に平均売上を割り当てない。
- 方法: カタログ期間と企画参加店舗で販売可能性を判定し、条件外は0円。条件内は販売可能な過去日の店舗×商品×曜日平均で予測し、履歴がなければ店舗×商品、商品、全体の順に補完する。
- 検証: 2022〜2023年を使い2024年を一括予測。2024年の予定が2023年末に既知という仮定を置く。6層の尺度は2022年の店舗×商品平均で2023年を予測した誤差から算出する。
- 実行: `uv run python -m exp.exp002_availability_weekday.run`

## 結果

- 2024年の6層正規化 RMSE: **0.828145**（exp001: 1.198543、低いほど良い）
- 2024年の日×店舗×商品 RMSE: **3,495.942円**（exp001: 6,532.162円）
- 2024年の販売条件外で正の実績売上: 0行。条件外の77,008行は0円と予測。
- 検証で店舗×商品×曜日平均を使った行は230,216行、商品平均への補完は216行。2025年予測ではそれぞれ229,704行と324行、条件外は76,572行。
- 保存先: `output/runs/20261117_003934_463595_exp002_availability_weekday/`

| 集計層 | 正規化 RMSE |
|---|---:|
| 日×店舗×商品 | 0.595247 |
| 日×店舗 | 1.142111 |

6層スコアは2024年を検証したローカル参考値であり、2025年の公式スコアではない。月×店舗の誤差が相対的に大きく、店舗ごとの水準変化への対応が次の検討点となる。2024年に検証するとき、その年の企画・カタログ予定が前年末に既知であるという仮定は別途確認が必要。
