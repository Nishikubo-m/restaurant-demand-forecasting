# exp051: 来店組数の同一条件の年次変化

- 仮説: EDA 13では売上変化を来店組数・着席率・着席組単価に分けている。売上数量相当値に加え、離脱を含む来店組数の変化が店舗需要の参考になる可能性がある。
- 変更: exp048の直近四半期・同一店舗とレイアウト・非祝日の364日前ペアについて、来店組数の前年比も履歴ログから算出し、数量相当売上の前年比の平方根と半分ずつ混合する。両方が14ペア以上で計算可能な店舗のみ適用し、他は元の方法を維持する。
- 検証: 2022〜2023年の履歴から2024年を一括予測。来店ログは履歴のみに結合し、予測対象日の来店実績は使用しない。予定情報は事前既知と仮定し、尺度は2022年平均による2023年誤差。来店数の変化と売上の因果関係は仮定できない。
- 実行: `uv run python -m exp.exp051_arrival_growth.run`

## 結果

- 2024年の6層正規化 RMSE: **0.376211**（exp048: 0.374623）。日次行 RMSE: **2,779.300円**。
- 来店組数の前年比を混合した店舗: 4店舗。
